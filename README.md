## 主要功能快速过一遍

**SQL 编辑器**：自动补全、关键字提示、自定义代码段，写 SQL 不用再盯着文档猜语法。

**可视化查询构建器**：拖拉拽就能组装查询，适合不那么熟悉 SQL 语法的用户。

**数据传输 & 同步**：跨库迁移数据、比对结构差异、同步更新——这功能对于要在开发库和生产库之间来回倒腾数据的人来说，是救命稻草级别的。

**导入 / 导出向导**：支持 Excel、Access、CSV 等格式，和业务部门对接数据变得没那么麻烦。

**数据模型工具（企业版 / 非商业版专属）**：把数据库结构转化成可视化 ER 图，写文档、讲需求、做 Code Review 的时候清晰多了。

**BI 工具（企业版 / 非商业版专属）**：内置数据分析功能，直接出图表，不用再倒腾 Excel 了。

**云同步**：连接设置、查询、模型可以同步到 Navicat Cloud，多台机器共享配置，团队协作也方便。

**安全连接**：SSH 隧道、SSL 加密，公网连数据库也不用太担心。
